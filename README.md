# Couriway No Reset Bingo

This website provides a means for people to play a fun game of bingo while watching Couriway's no reset speedruns!

There are two different modes in this: regular bingo, and 100k bingo. 

### Regular Bingo
Regular bingo is the main mode, and is designed to be played over the course of one stream. In this mode, you would generate a card, and then see how many squares you can mark off throughout the runs that day.

### 100k Bingo
The 100k bingo mode is one static bingo card that contains larger, more long term goals that will hopefully be completed over the course of the 100k challenge. 
This card is read-only, showing the current status of the board.

## Running Locally

Install dependencies

```
pnpm install
```

Run the development server

```
pnpm run dev
```
